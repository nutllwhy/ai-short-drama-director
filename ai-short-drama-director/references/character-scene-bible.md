# 人物与场景圣经

本文件只在剧情大纲得到用户确认后读取和执行。它把故事角色与地点变成可复用的生成锚点，防止分镜逐段临时发明脸、服装和空间。大纲未确认时不得提前生成人物图或场景图。

## 先做素材分级

### 人物分级

| 人物等级 | 判定 | 必做内容 | 图像要求 |
|---|---|---|---|
| 主角 | 故事主要行动者 | 完整人设卡、服装组、表演基线、声线说明 | 单人三视图；必要时为明确换装另做一组三视图 |
| 反派 | 持续制造主要阻力 | 完整人设卡、服装组、表演基线、声线说明 | 单人三视图 |
| 常驻具名配角 | 跨多个段落或剧集复用，并影响情节 | 完整人设卡、与主角关系、固定动作习惯 | 单人三视图 |
| 一次性具名配角 | 有姓名或明确身份，只承担一场功能 | 简版人设卡、身份、服装、表演任务 | 单人身份图；连续多段、多角度动作时才升级为三视图 |
| 非实体系统 / 器灵 / 画外人格 | 持续发出任务、奖励、限制或提醒，但没有固定真人身体 | 系统实体卡、规则边界、说话语气、独立声样、界面视觉规范 | 有可见面板时制作系统 UI 锚点；无可见界面时可不生图；一旦实体化出镜，改按常驻具名配角处理 |
| 无名群演 | 宾客、员工、侍卫、路人等群体 | 人群数量、阶层、服装与行为约束 | 默认不单独生图；只有构图复杂时做对应站位图 |

“三视图”指同一人物、同一妆造、同一服装的正面全身、标准侧面全身、背面全身。三格只表示一个人，不能出现三张不同的脸、不同首饰或不同服装。它用于锁身份，不作为剧情首帧，也不带剧情动作。

### 场景分级

| 场景等级 | 判定 | 必做内容 | 图像要求 |
|---|---|---|---|
| 核心场景 | 跨段复用、承担关键冲突，或空间方位会影响连续性 | 完整场景卡、空间关系、光线、固定物 | 无人场景锚点 |
| 次要场景 | 只出现一段，空间简单 | 简版场景卡 | 只要进入实际生成段，就做一张简化无人场景参考并以 `scene_variant` 登记；只被对白提及而未出镜时不进入生成场景清单 |
| 同址明显变体 | 同一空间跨昼夜、损毁前后或布置发生剧情性变化 | 继承基础场景卡并只写变化项 | 变化会影响构图时另做变体锚点 |

核心场景锚点和进入生成段的次要场景参考都必须无人、无剧情动作、无可移动手持道具。保留建筑结构、门窗、固定家具、主光方向和镜头可用的空间余量。桌上信件、酒杯、药瓶、武器、手机、文件等随剧情变化的物件不放进基础场景锚点。

## 人物人设卡

每个需要人设卡的角色至少填写：

| 字段 | 内容 |
|---|---|
| 人物 ID / 姓名 | 唯一编号与剧中姓名 |
| 人物等级 | 主角 / 反派 / 常驻具名配角 / 一次性具名配角 / 非实体系统 |
| 叙事功能 | 这个人物改变剧情的方式 |
| 基本身份 | 年龄段、性别表达、职业/阶层、时代身份 |
| 关系与利益 | 与主角的关系、想得到什么、最怕失去什么 |
| 面部锚点 | 脸型、眉眼、鼻唇、肤色、明显但不过度复杂的识别特征 |
| 体态锚点 | 身高体型、肩背、站姿、步态 |
| 发型与妆面 | 固定轮廓、发饰、妆感；不依赖“漂亮/帅气”等空词 |
| 常驻服装 | 版型、材质、主辅色、鞋履和固定配件 |
| 表演基线 | 平常表情、情绪外露程度、习惯动作、说话节奏 |
| 声线说明 | 音色、语速、力度、年龄感；独立声样编号另记 |
| 禁止漂移 | 不能变化的脸、发型、服色、年龄和标志物 |
| 首次/复用 | 首次出现段落与预计复用范围 |

一次性具名配角可以缩减“表演基线、声线、复用范围”，但身份、年龄段、面部锚点、服装和当前情绪任务必须明确。若配角有对白，仍须使用自己的声样，不能借用主角或反派音色。

非实体系统另建系统实体卡，至少写：系统 ID、出现条件、能做与不能做的事、奖励与代价、信息展示格式、面板主辅色和字体层级、提示音、声线、固定称呼、是否会撒谎、当前等级与跨段状态。系统面板属于可复用界面资产，不把它伪装成人物三视图；只有系统真的以固定人物形象出镜时，才补人物卡与三视图。

## 人物图提示词

三视图使用中性摄影棚或干净浅色背景，人物自然站立，双臂放松，不持物、不说话、不表演剧情。提示词至少写清：

```text
同一位{时代/地域身份}{年龄段}{性别表达}的单人全身三视图，从左到右依次为正面全身、标准右侧面全身、背面全身。三格是同一个人，同一张脸、同一发型、同一妆面、同一套服装与配饰。{面部锚点}，{体态锚点}，穿{服装版型、材质、主辅色、鞋履与固定配件}。自然站立，双臂放松，无手持物，无剧情动作，无文字，无水印，真实人物摄影，细节清晰。
```

一次性具名配角身份图使用单人正面或四分之三身构图，展示脸、身份服装和当前场景所需的基本情绪，不加入其他人物或关键剧情结果。

每张人物图生成后逐一检查：

- 三格是否确为同一人、同一年龄、同一服装和同一配件；
- 正面、侧面、背面是否完整，是否出现额外人物或重复肢体；
- 发饰、衣襟、腰带、鞋履、工牌、眼镜等固定身份物是否前后吻合；
- 图中是否混入剧情道具、字幕、水印或不合时代的物件；
- 角色之间是否有足够视觉区分，避免主角与配角长成同一张脸。

不合格时只重做对应人物图，并根据实际错误改提示词；不要用相近但不一致的第二张肖像补数量。

## 场景卡

每个核心场景至少填写下列完整字段；进入生成段的次要场景也要建简版卡，至少保留场景 ID、剧情功能、时代地点、时段、空间结构、光线、可变道具和禁止漂移：

| 字段 | 内容 |
|---|---|
| 场景 ID / 名称 | 唯一编号与剧中称呼 |
| 剧情功能 | 在此发生的核心冲突或行动 |
| 时代与地点 | 年代、地域、室内/室外、建筑类型 |
| 时段与天气 | 日夜、主光色温、窗外环境 |
| 空间结构 | 门窗、走道、台阶、桌椅等固定关系 |
| 固定家具 | 不随分镜变化的陈设、材质和主辅色 |
| 方位约定 | 主入口、人物常用站位、镜头轴线和左右关系 |
| 声音基线 | 稳定环境声，如雨声、空调、街声、宾客低语 |
| 可变道具 | 在分镜中出现、由连续性台账管理的物件，不画入基础锚点 |
| 禁止漂移 | 不能新增或改变的时代、格局、门窗、主要家具和色彩 |
| 首次/复用 | 首次出现段落与复用范围 |

场景锚点提示词至少写清空间、固定家具、光线和无人要求：

```text
{时代与地域}的{场景名称}，无人空场景。{门窗、走道、台阶、桌椅的固定空间关系}，{固定家具材质与主辅色}，{时段与主光方向}。保留人物活动和镜头运动空间；没有人物，没有手持道具，没有剧情结果，没有文字、字幕和水印，真实影视置景，{项目比例}构图。
```

生成后检查：场景是否无人；门窗、入口、桌椅与轴线是否清楚；固定物是否符合时代；是否混入人物、酒杯、文件、手机等可变道具；竖屏是否给人物站位和镜头留出空间。复杂场景可补一张站位示意，但站位图不替代无人锚点。

## 文件命名与素材包位置

使用稳定 ID，不用“最终版2”“新图”等含糊名称：

```text
02_人物圣经/
  CH01_林野/
    CH01_人物卡.md
    CH01_三视图.png
    CH01_三视图提示词.txt
  CH02_罗骁/
    CH02_人物卡.md
    CH02_三视图.png
    CH02_三视图提示词.txt
  CH04_审计主管/
    CH04_人物卡.md
    CH04_身份图.png
    CH04_身份图提示词.txt
03_场景圣经/
  SC01_发布会后台/
    SC01_场景卡.md
    SC01_无人锚点.png
    SC01_无人锚点提示词.txt
```

人物图、场景图和对应生图提示词都进入素材包；图片还必须在最终飞书文档的人物/场景区块内嵌展示。文档中的图片标题保留 ID 和文件名，逐段表通过这些 ID 引用，避免同一素材出现多个叫法。

## 进入分镜前的检查

只有下列条件满足，才开始逐段提示词编译：

- 确认大纲中的全部具名角色已分级；
- 人物 ID、核心场景 ID 与 `01_剧情/故事契约.json` 精确一致；
- 主角、反派、常驻具名配角均有通过检查的三视图；
- 一次性具名配角均有身份图，或明确记录为何不需要出镜参考；
- 非实体系统已完成系统实体卡；有可见面板时已有系统 UI 锚点，有对白时已有自己的声样；
- 全部核心场景均有通过检查的无人锚点；进入生成段的次要场景和明显变体也有自己的无人参考图与生图提示词；
- 人物卡、场景卡的 ID、文件名和图像一一对应；
- 换装、昼夜变体和可变道具已分清，不污染基础锚点。

缺项要标为 `待补`，并同步影响到使用该素材的生成段；不能把“已写提示词”视为素材已就绪。
