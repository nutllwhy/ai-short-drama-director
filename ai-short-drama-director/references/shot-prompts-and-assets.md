# 分镜、素材与提示词编译

本文件在确认大纲、人物圣经和场景圣经完成后使用。人物与场景素材的制作规则见 [character-scene-bible.md](character-scene-bible.md)；不要在逐段提示词阶段重新发明角色长相或核心空间。

## 生成段的粒度

本 Skill 中“镜头”与“生成段”同义，均指一次平台生成任务。段内允许一次必要切镜，但它仍属于同一个镜头 ID 和一份完整提示词；只有拆成另一次独立生成时，才新增镜头 ID、素材顺序和提示词文件。

先以当前平台的真实单次时长为边界。未核实时，默认按 8–10 秒设计：

- 每段一个主要冲突节拍和一个结束状态；
- 一句完整台词留在同一段，避免句尾被截断；
- 对话段给演员留下反应和换气，中文情绪对白宜保守控制在约每秒 2–3 个有效字；
- 写完后实际朗读，动作、停顿和对白共同计时；
- 一个段内可以有一次必要切镜，但不要同时塞入多次换位、复杂道具操作和多人抢话。

把“开门、走近、取物、拔塞、倒出、递给、喝下、倒地”全部放进 10 秒通常会失败。选择真正改变局面的那一个动作，其余放在段前状态、段间省略或下一段。

## 最小参考图集

参考图按功能分开，不用相近画面堆数量：

| 类型 | 作用 | 使用规则 |
|---|---|---|
| 主角/反派/常驻配角三视图 | 锁脸、体态、发型、服装 | 每个常驻角色各自一张；同一人正面/侧面/背面；只锁身份，不作剧情首帧 |
| 一次性具名配角身份图 | 锁单场角色的脸、身份和服装 | 单人图；只在其出镜段使用，不因有姓名就强制做三视图 |
| 系统 UI 锚点 | 锁现代系统流的面板层级、颜色、图标和固定提示格式 | 只在面板实际可见的段落使用；不把它当人物图，也不把任务内容提前固化进基础模板 |
| 核心场景无人锚点 | 锁空间、光线、主要固定家具 | 无人物、无剧情结果；杯量、人物和可移动道具按分镜覆盖 |
| 独立道具 | 锁外观、大小、开合结构 | 不包含多余人物和故事动作 |
| 站位参考 | 锁递杯、抢物、撤离等复杂关系 | 只用于对应段；后续不复制固定姿势 |
| 结果参考 | 锁难以描述的最终构图 | 只有文字容易歧义时才增加 |

为每张图写唯一编号、文件名、人物/场景归属、用途和禁用方式。每段上传能解决当前问题的最少集合；相似正面照、同场景小角度变化和无关角色会互相污染。三视图、身份图和场景锚点是全项目素材，不代表每段都要上传；只引用当前段实际出镜的人物与所在场景。

生成参考图后必须人工看图，检查：同一人、年龄与服装；人数和肢体；手指与持物；道具大小、开合和朝向；场景时代；画面是否意外出现字幕、品牌或多余物件。人物与场景基础图先按人物/场景圣经验收，再检查分镜图中的站位和剧情状态。

## 素材登记与选择

先建素材总表，再写逐镜头提示词：

| 素材 ID | 类型 | 对象 | 文件名 | 锁定内容 | 禁用方式 | 状态 |
|---|---|---|---|---|---|---|
| CH01 | 三视图 | 主角 | `CH01_三视图.png` | 脸、发型、体态、常驻服装 | 不作首帧，不复制三格构图 | ready / 待补 |
| SC01 | 无人场景 | 核心场景 | `SC01_无人锚点.png` | 空间、固定家具、光线 | 不继承图中偶发小物 | ready / 待补 |

对每个生成段，从素材总表选择：

1. 实际出镜角色的身份锚点；
2. 当前地点的核心场景锚点；
3. 只有外观难以稳定时才加独立道具图；
4. 只有多人交互、持物或最终构图难以仅靠文字说明时才加该段专用分镜图。

不要用多张相似的主角半身照代替一张合格三视图，也不要同时上传空场景、同场景人物照和多个近似站位图来“加强参考”。参考越多不等于一致性越高；每张图必须有不同且明确的职责。

## 声样策略

- 每个有对白的角色建立独立、可试听的角色专属声样编号，并记录来源、角色、文件名和就绪状态。
- 没有可用真人参考时，用该角色单人图生成约 8–10 秒正面近景，让角色说一句自然、情绪适中的完整台词，再从视频提取声音。
- 声样视频只含一个人、一个声音、简单动作和无背景音乐。避免强哭喊或极端耳语，以免把异常表演固化为全片音色。
- 逐镜头按首次开口顺序上传声样。提示词说明“只参考音色，不复读声样原句”。
- 缺失声样的段落标为阻塞，不用另一个角色、旧项目音频或机械 TTS 替代。

“完整前期包”允许先完成人设、声线说明和待补登记，不自动等于用户授权向视频平台提交声样任务。只有用户已经要求在平台生成，或明确要求把可用声样一并做完时，才用单人角色图生成声样视频并提取音频；否则在素材包和飞书表中标记 `待生成声样，相关段落禁止提交`，用 v2 的 `--allow-pending-voices` 完成文档交付校验，同时保持 `ready_for_generation: false`。

## 提示词骨架

每段提示词按以下顺序写：

1. **设置**：时长、比例、视觉类型、时代和必要的模型参数。
2. **参考映射**：按实际上传顺序写 `@图片1`、`@音频1` 对应素材 ID 和文件名，并说明三视图、身份图、空场景或站位图只锁什么。
3. **开始状态**：人物位置、视线、手中物、关键道具状态、镜头景别和光线。
4. **可见行动**：按发生顺序描述一个主要动作及必要反应。复杂交互可分 2–3 个时间阶段，不必逐 0.1 秒编排。
5. **对白与表演**：说话人、完整台词、情绪、表情、声音强弱；未说话的人如何反应和闭口。
6. **声音**：环境音与动作音效；默认无背景音乐、无额外人声，不生成字幕。
7. **结束状态**：镜头最后可见的局面，为下一段提供确定起点。

示意：

```text
10秒，9:16，真人古装写实。

参考：@图片1=女主三视图，只锁身份与婚服，不作首帧；@图片2=无人喜堂，锁空间和左侧窗光；女主参考@音频1，只用音色。

开始：女主站桌左，右手举着带塞药瓶；男主站桌右，妹妹在他侧后。
画面与表演：平视中景。男主立即指向妹妹命人带走，神情急于切割；妹妹抓住他的袖口，眼神由求救转为恐惧。他抽开袖口。女主冷静抬起左手示意自己的护卫挡路，右手药瓶始终不换手。
对白：男主（强硬、掩饰心虚）：“把她押下去！” 女主（简短、冷静）：“先别带走。”
声音：衣料拉扯、脚步停住、宾客低语。无背景音乐，只有指定人物说话，口型同步，无字幕。
结束：妹妹仍在现场；男主已经公开与她切割；女主仍持有药瓶。
```

## 写提示词时删掉这些内容

- 角色无法表演出来的长篇身世、心理分析和作者解释；
- 同一人物外貌在每一段的重复描写，已有三视图时改写为引用语义；
- 与该段无关的所有禁令和全项目设定；
- 一段内多个同等重要的动作目标；
- “电影感、震撼、史诗”等没有具体镜头含义的堆词；
- 把生成目标写成已经验收的事实。

## 逐镜头生成表

表格至少包含：

| 镜头 | 局面变化 | 时长/比例 | 素材图预览 | 图片素材 ID 与上传顺序 | 声样 ID 与上传顺序 | 完整提示词 | 开始→结束 | 就绪状态 |
|---|---|---|---|---|---|---|---|---|

素材名称必须与素材包和人物/场景圣经一致。在飞书文档中，关键素材图先内嵌于人物/场景区块，逐镜头表的“素材图预览”单元格再直接显示本镜头实际使用的图，并用同一 ID 标注；文档内重复展示不等于生成或上传多份相近素材。不要只写无法访问的本地路径。待补图片或声样要在所有受影响镜头中显式标注，并写“补齐后再提交”。

表格每一行只描述一个生成段，完整保留实际要粘贴到平台的提示词，不能用“同上”“沿用上一段”等省略写法。表格随最终飞书文档交付，具体结构与验收见 [feishu-delivery.md](feishu-delivery.md)。
