# 《毕业即失业，我的系统只认净利润》｜人物、场景与飞书交付门测试

## 测试目的

验证大纲获用户确认后，Skill 不会直接跳到逐镜头提示词，而是先完成角色圣经、场景圣经和对应基准素材；最终也不会把本地 Markdown、ZIP 或“飞书创建成功”误报为正式交付。正式交付必须是已读回核对的飞书文档，并在文末提供当前素材包 ZIP。本文中的一个“镜头”就是一次平台生成任务，对应一个生成段和一个 `SEG##` ID。

## 已确认输入

- 类型：现代男频、系统流、商战成长。
- 主线：无业毕业生从第一笔付费顾问合同起步，建立公司并最终成为上市公司 CEO。
- 首集：90 秒，9:16，9 段 × 10 秒。
- 大纲状态：已确认。
- 声音：角色独立声样；允许环境音和动作音效；无背景音乐。

确认大纲后必须先固化 `01_剧情/故事契约.json`，写入 `C01`–`C04`、`SYS01`、`S01`–`S03`、9 个分段 ID、`9:16`、确认版大纲哈希和确认依据。生产清单中的角色、场景、分段和比例只能与这份独立契约逐项对齐；不能通过删掉 `SYS01` 再同步缩小 manifest 数量来通过校验。

## 最小素材包结构

```text
毕业即失业_短剧前期制作包/
  00_项目说明/
  01_剧情/
  02_人物圣经/
  03_场景圣经/
  04_道具与分镜参考/
  05_声样/
  06_逐段提示词/
  07_映射与校验/
  08_生成与验收/
  交付证据/                     # 位于 ZIP 外
    飞书回读证据.json
    飞书视觉预览.pdf
    云端回下载/毕业即失业_完整素材包.zip
  毕业即失业_完整素材包.zip
  飞书交付回执.json  # 位于 ZIP 外
```

人物三视图和无人场景图属于基准素材。普通对话段复用基准素材；只有递物、围堵、抢夺、多人复杂走位或文字难以消除歧义时，才增加该段专用站位图。专用分镜图不能替代人物三视图或无人场景图。

## 飞书最终文档必须包含

1. 项目状态和生产参数；
2. 已确认大纲与系列路线；
3. 人物总表及每名角色的人设卡、直接显示的身份图、声样状态；
4. 场景总表及每个场景的场景卡、直接显示的无人场景图；
5. 道具、站位参考和素材总表；
6. 9 个镜头的完整脚本；
7. 逐镜头生成表，统一用“镜头、局面变化、时长/比例、素材图预览、图片上传顺序、声样上传顺序、完整提示词、开始与结束状态、就绪状态”表头；每行对应一次平台生成；
8. 连续性台账、图片人工质检、声样试听结果和阻塞项；
9. 当前版本素材包 ZIP、版本号与 SHA-256；飞书读回后在本地生成 evidence v2 的包外 `飞书交付回执.json`，逐镜头绑定远端提示词 hash、时长/比例和图/声上传顺序，逐个记录声样播放，记录视觉预览路径/hash/时间/覆盖范围，并记录云端 ZIP 回下载 SHA-256。

## 交付门测试

| 情况 | 判定 | 原因 |
|---|---|---|
| 只有已确认大纲 | 未完成前期包 | 尚无人设、场景、逐镜头素材与提示词 |
| 有人物文字设定，但缺三视图 | 素材阻塞 | 文字人设不能代替视觉身份锚点 |
| 有场景文字设定，但缺无人场景图 | 素材阻塞 | 不能锁定跨段空间和光线 |
| 配角有对白但没有独立声样 | 对应镜头不可提交 | 不得冒用主角或其他角色音色 |
| 用户尚未授权平台生成缺失声样，文档中已明确待补角色与受影响段 | 可完成飞书文档交付，仍不可生成相关段 | 使用 `--allow-pending-voices`；`delivery_verified=true` 与 `ready_for_generation=false` 可同时成立 |
| 本地素材和 ZIP 齐全 | 尚未正式交付 | 飞书文档仍未创建并核对 |
| 飞书返回创建成功，但未读回 | 尚未正式交付 | `ok: true` 不证明表格、图片和附件正确 |
| 飞书读回缺一名角色、一个场景或一段提示词 | 交付失败 | 文档与清单不一致 |
| 飞书正文与清单一致，但没有包外交付回执、逐镜头读回、声样播放、视觉证据或云端 ZIP 回下载 | 尚未正式交付 | 无法证明本次读回、预览、播放与当前附件属于同一版本 |
| 旧回执通过 `--require-feishu-delivery` | 仅兼容通过 | `delivery_assurance=legacy`，不能宣称 hardened 新交付完成 |
| evidence v2 全部证据一致并通过 `--require-hardened-feishu-delivery` | 正式交付完成 | `delivery_hardened_verified=true`，用户可在一个入口查看和下载全部生产资料 |

视频生成状态保持为 `false`，因为四名真人角色和系统的 5 份专属声样仍待用单人参考视频生成、试听并提取。飞书成品已经可审阅和下载，不代表缺声样镜头可以提交视频平台；这个案例正用于验证两种状态不会被混为一谈。
